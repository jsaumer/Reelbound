# 07 — Slot Types

A **slot type** is the payout-evaluation ruleset: how a spin resolves and pays. It's a distinct progression/gameplay axis from **symbol density** (what's on the reels). The same symbol pool plays very differently under different types — a wild-heavy build is far stronger in ways-to-win than on fixed paylines — so type and density *interact*, and that interaction is a feature: unlocks aren't universally good, they're good for *certain types*.

The type also sets the **stage's feel**. Chosen to span the volatility spectrum so each stage has a distinct rhythm and rewards a different build. That directly reinforces the "two skills" niche: you adapt both your build and your play to the type in front of you.

## The starting five

| # | Type | How a spin pays | Volatility | Economy feel | Native bonus (see `08`) |
|---|------|-----------------|-----------|--------------|-------------------------|
| 1 | **Payline (classic lines)** | Matches along fixed left→right lines. | Moderate | The legible baseline. Steady, teachable. | Free spins |
| 2 | **Ways-to-win (243-style)** | Any matching symbols on adjacent reels pay, position-independent. | Low–moderate | Consistent grinder. Density-hungry; steady conversion. | Free spins w/ persistent multiplier |
| 3 | **Cluster + cascade** | Groups of touching symbols pay; winners vanish, new symbols drop, chains continue. | High (chain-driven) | Combo engine. Flashiest, most juice-friendly; skill ceiling in chains. | Cascade multiplier ramp |
| 4 | **Hold-and-spin / respin** | Trigger a mode: paying symbols lock, respin the rest for N attempts, building a payout. | Moderate–high | A built-in press-your-luck engine; pairs with bank-vs-press. | Respins (the mode *is* the bonus) |
| 5 | **Megaways-style (variable reel height)** | Each reel's visible symbol count changes per spin, so ways swing wildly. | Very high | Feast-or-famine against the spin deadline. The boss-y type. | Free spins w/ unlimited multiplier |

**Spread:** one baseline (1), one consistent (2), one combo (3), one press-your-luck (4), one high-volatility (5). Each demands a different build and creates a different stage rhythm.

## The starting point

The player begins on **Payline** only — the cleanest teaching type for the three-pool economy. The other four are **unlocked through meta-progression**, widening the pool of stage types the game can present.

## Open decision — is slot type stage-dictated or player-chosen? *(D13)*

A real fork that shapes everything about how types are used:

- **Stage-dictates:** each stage *is* a type ("a cluster stage"), and you build to fit it. Type becomes a challenge to adapt to. Maximizes variety and the "read the stage, then build" skill.
- **Player-chosen/carried:** you pick/unlock a type you bring into stages. Type becomes a build to specialize in. Maximizes mastery and identity.
- **Hybrid:** the stage constrains (offers 2–3 types), you choose within it.

**Lean:** stage-dictates for the first prototype (simplest, most legible, forces adaptive play), revisit toward a hybrid once the five types are individually proven. *(Logged as D13.)*

## Interaction with symbol density (a designed feature, not a bug)

Because unlocks add *density* of symbols/wilds/multipliers/bonus symbols, and each type reads the reels differently:

- Wilds are worth far more in **ways-to-win** and **cluster** (more adjacency/grouping) than on fixed **paylines**.
- Bonus/charge symbols matter most where the native bonus is strongest for the stage goal.
- A high-variance density build is punishing in **Megaways** (already swingy) but can be the *point* there.

This means a player's unlocked symbol pool has *type-dependent* value — deepening the build decision and giving unlocks texture beyond "strictly better."
